Szenarien & Kommandos

Hier die empfohlenen Kommandos für die verschiedenen Input-Layouts:

1) AC-3 5.1 → Stereo AC-3
ffmpeg -i input_ac3_5.1.ac3 \
  -c:a ac3 -b:a 384k \
  -dmix_mode loro \
  -loro_cmixlev 0.707 \
  -loro_surmixlev 0.707 \
  output_ac3_stereo.ac3

2) DTS (5.1) → Stereo AC-3
ffmpeg -i input_dts_5.1.dts \
  -c:a ac3 -b:a 384k \
  -dmix_mode loro \
  -loro_cmixlev 0.707 \
  -loro_surmixlev 0.707 \
  output_ac3_stereo.ac3

3) E-AC-3 (egal ob 5.1 oder 7.1) → Stereo AC-3
ffmpeg -i input_eac3_multi.eac3 \
  -c:a ac3 -b:a 384k \
  -dmix_mode loro \
  -loro_cmixlev 0.707 \
  -loro_surmixlev 0.707 \
  output_ac3_stereo.ac3

4) AC-3 oder DTS 7.1 → Stereo AC-3

Für 7.1-Quellen verhält sich der Downmix analog zu 5.1: zusätzlicher Surround-Kanal (z. B. Back Surround) wird ebenfalls mit –3 dB gemischt:

ffmpeg -i input_7.1.ac3 \
  -c:a ac3 -b:a 384k \
  -dmix_mode loro \
  -loro_cmixlev 0.707 \
  -loro_surmixlev 0.707 \
  output_ac3_stereo.ac3






FFmpeg-Kommandos für deine 4 Szenarien

Hier drei nahezu identische Kommandos – die nur an die Input-Variante angepasst sind. Alle führen zu Stereo-AC3 mit moderatem LFE-Bassboost und optionaler Lautstärkeanhebung:

1) AC-3 5.1 → Stereo AC-3 mit LFE-Boost
ffmpeg -i input_ac3_5.1.ac3 \
  -af "pan=stereo|FL=0.707*FL+0.707*FC+0.707*BL+0.5*LFE|FR=0.707*FR+0.707*FC+0.707*BR+0.5*LFE,volume=1.5" \
  -c:a ac3 -b:a 384k \
  output_ac3_stereo_lfeboost.ac3

2) DTS 5.1 → Stereo AC-3 mit LFE-Boost
ffmpeg -i input_dts_5.1.dts \
  -af "pan=stereo|FL=0.707*FL+0.707*FC+0.707*BL+0.5*LFE|FR=0.707*FR+0.707*FC+0.707*BR+0.5*LFE,volume=1.5" \
  -c:a ac3 -b:a 384k \
  output_ac3_stereo_lfeboost.ac3

3) E-AC-3 (5.1 oder 7.1) → Stereo AC-3 mit LFE-Boost
ffmpeg -i input_eac3_multi.eac3 \
  -af "pan=stereo|FL=0.707*FL+0.707*FC+0.707*BL+0.5*LFE|FR=0.707*FR+0.707*FC+0.707*BR+0.5*LFE,volume=1.5" \
  -c:a ac3 -b:a 384k \
  output_ac3_stereo_lfeboost.ac3

4) AC-3 oder DTS 7.1 → Stereo AC-3 mit LFE-Boost
ffmpeg -i input_7.1.ac3 \
  -af "pan=stereo|FL=0.707*FL+0.707*FC+0.707*BL+0.5*LFE|FR=0.707*FR+0.707*FC+0.707*BR+0.5*LFE,volume=1.5" \
  -c:a ac3 -b:a 384k \
  output_ac3_stereo_lfeboost.ac3
